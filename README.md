# Sloppertizer — redesign engine experiment

Our first benchmark is [WorkFlow AI Pro](https://github.com/TinyikoMamban/workflowai-pro), an MIT-licensed AI-generated SaaS application. We evaluate a genuine frontend redesign, not a recolor.

**Scope:** landing-page transformation with preserved routes and interactions, then desktop/mobile screenshot review. This is an experimental engine, not a launched SaaS.

Use `npm test` to run the engine's guardrail tests. See `docs/pilot.md` for the experiment procedure. The original project is never modified.
